## 👋 About Me

Hi! I’m **Nikhil**, a front-end enthusiast exploring the vast world of modern web development.  
This project is a **clone of the Ochi website**, built to practice **React, Next.js, and Locomotive Scroll** for smooth scroll animations and interactive UI experiences.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Next.js  
- **Styling & Animations:** Tailwind CSS, Locomotive Scroll  
- **Routing & Navigation:** Next.js Pages  
- **State Management:** React Hooks

## 🚀 Getting Started

Follow these steps to run the project locally:

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/yourusername/ochi-clone.git
cd ochi-clone
```
2️⃣ Install Dependencies
```bash
Copy code
npm install
# or
yarn install
```
3️⃣ Run Locally
```bash
Copy code
npm run dev
# or
yarn dev
Open http://localhost:3000 in your browser to see the project.
```
